# Optimization of Radio Array Telescopes to Search for Fast Radio Bursts

This repository contains the **corrected version** of the analysis and working paper.
The original version is preserved under the [`v1.0` tag](https://github.com/WVURAIL/Optimization-of-Radio-Array-Telescopes-to-Search-for-Fast-Radio-Bursts/tree/v1.0).

The [errata](ERRATA.md) explain what changed and how the corrections affected the results.

- [Corrected paper](paper/frbarray.pdf)
- [Before/after comparison](comparison/results-comparison.pdf), with paired figures and numerical tables
- [Analysis notebooks](code/) and [manuscript source](paper/frbarray.tex)
- [Reproduction instructions and comparison data](comparison/README.md)

The original paper by Peterson, Bandura and Sanghavi is available as
[arXiv:2001.06526](https://arxiv.org/abs/2001.06526). The corrected paper here is an
unpublished working draft. See [CITATION.cff](CITATION.cff) for citation metadata
and [NOTICE](NOTICE) for attribution and rights information.
